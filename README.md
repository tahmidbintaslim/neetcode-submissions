# NeetCode submissions

My solutions to practice problems on [NeetCode.io](https://neetcode.io), committed here by NeetCode's GitHub Sync.

## Contents

The repository holds two Python solutions, both in the `Python Coding Interviews` folder:

| Problem | File | What it does |
| --- | --- | --- |
| Sort ascending | `Python Coding Interviews/python-sort-ascending/submission-0.py` | Returns sorted copies of a list of words, a list of integers and a list of floats with `sorted()` |
| Sort descending | `Python Coding Interviews/python-sort-descending/submission-0.py` | The same three functions, in descending order with `sorted(..., reverse=True)` |

New submissions arrive as new files and this table is not updated with them, so the folders are the full record.

## Layout

Each submission is its own file, grouped by course folder and then problem ID:

```
<course folder>/
  <problem-id>/
    submission-0.<ext>   first submission
    submission-1.<ext>   later submissions, if any
```

## Running a solution

Each file is a standalone Python 3 script that uses only the standard library. The lines under `# do not modify below this line` are NeetCode's test calls; they print the results.

```bash
python3 "Python Coding Interviews/python-sort-ascending/submission-0.py"
```

## How the sync works

NeetCode's GitHub Sync commits a file here when a solution is submitted on neetcode.io (every submission or accepted ones only, depending on the setting). Past solutions can be pushed in bulk, and single submissions can be synced or removed from a problem's submission history. The settings are at [neetcode.io/profile/github](https://neetcode.io/profile/github).
